# Learner Project Tracker

A web app that lets TechDojo learners submit their daily project work and see review feedback, and lets the instructor review submissions and write feedback once, inside the product.

## Problems it addresses

- The instructor writes feedback in a sheet and then copies it into each learner's chat.
- Learners have not received individual feedback.
- Learners are unclear on what to submit and how.

## Users

- **Learner:** sees the day's requirements, submits a link, and reads feedback.
- **Instructor:** reviews submissions, writes and saves feedback, and checks who is still unreviewed.


Each page uses semantic HTML: `<header>`, `<main>`, a labelled `<nav>`, and `<footer>`.

## How to view it

No build step is needed. Clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/LA1385/learner-project-tracker.git
cd learner-project-tracker
```
